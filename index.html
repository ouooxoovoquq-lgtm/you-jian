#4 论证角度全面替换 1.1 → 1.2 改动 论证从"否定法定资格"升级为"转嫁经营风险定性" 论证逻辑经营风险
1.1
本次仅为客户方业务调整、项目裁撤，贵司整体正常经营，不属于法定可单方安排员工待岗的情形。
↓
1.2
本次安排系因客户方业务调整、项目裁撤引起，贵司作为用人单位整体仍正常经营，且通知中亦载明"公司会为你在内部匹配合适的新项目"。这说明贵司并未发生法定停工停产情形，单一客户项目终止形成的岗位空档，属于贵司应自行承担的经营风险，不能等同于法定停工待岗。
改动原因1.1 只是笼统说"不属于法定情形"；1.2 新增了两大论据：（a）引用公司自己的通知原文"公司会为你匹配合适的新项目"，反过来证明公司自己都承认还在经营；（b）把结论从"不符合法定"推进到"这是公司应承担的经营风险"——逻辑链从"违法"变成"公司自己该扛"。
侧重方向论证从"否定法定资格"升级为"转嫁经营风险定性"
#5 薪酬条款重写 + 加降薪定性 1.1 → 1.2 改动 从"程序违规"升级为"实质劳动条件违约" 条款定性变相降薪

改动原因1.1 只说"单方变更劳动合同履行方式"，1.2 加了三个关键词：①"并降低薪资"——点出经济实质；②"未按劳动合同约定提供劳动条件"——用劳动合同法第38条的精确表述；③"变相降薪"——把待岗+降薪的组合定性为实质降薪，为后续被迫解除铺垫。
侧重方向从"程序违规"升级为"实质劳动条件违约"
#6 报到申明 + 每日书面申请 1.1 → 1.2 改动 从被动"等候"变为主动"要求 + 留痕" 行动策略证据留痕

↓
1.2

改动原因1.1 是被动姿态"等候安排"；1.2 变成主动"要求提供劳动条件"，并新增了最关键的实操细节——每天书面申请工作。这是为了防止后续被反咬"员工怠工"，用书面记录把责任牢牢钉在公司不提供工作上。同时删掉了"打卡"二字，弱化"服从管理"的暗示。
侧重方向从被动"等候"变为主动"要求 + 留痕"
#7 诉求第3点 + 保留38条武器 1.1 → 1.2 改动 从主动求协商 → 保留被迫解除的法律武器 法律威慑38条
1.1
请及时与本人协商劳动合同变更或者协商解除事宜，并依法落实经济补偿。
↓
1.2
请贵司就后续安排主动与本人协商…亦保留依据《劳动合同法》第三十八条主张权利的一切法律途径。
改动原因1.1 的诉求是"请及时协商解除+补偿"，属于主动提出解约；1.2 删掉了主动解约的表述，改为"保留依据38条主张权利"——这意味着主动权牢牢握在自己手里：是公司违法在先，我随时可以被迫解除并拿到经济补偿，而不是我主动解约。这是根本性的姿态转变。
侧重方向从主动求协商 → 保留被迫解除的法律武器
